# 数据与隐私

## 原则

Mihomo Meter 采用本地优先、最小采集和明确口径原则。

## MVP-1 保存的数据

- Controller 回环地址
- macOS Keychain 中的 Controller Secret

实时分类、连接运行基线、Mihomo 版本和速率窗口只保存在内存中，应用退出后不保留。

以下数据将在 MVP-2 经过独立设计和迁移后才会保存：

- 分钟级 Proxy、DIRECT、REJECT 和未知流量汇总
- 本地统计记录点
- Mihomo 内核会话标识

## 不保存的数据

- Controller Secret 明文
- 订阅地址和访问令牌
- 完整域名或目标 IP
- 进程完整路径
- 单连接长期明细
- 网络内容

Controller Secret 不写入 UserDefaults、日志、测试样例或流量数据；应用只在用户首次手动输入后保存到自身 macOS Keychain。

## 网络行为

- 默认只允许连接 `127.0.0.1` 或 `::1` 上的 Controller。
- 不向项目维护者或第三方上传流量统计。
- 不修改 Mihomo、Clash Verge Rev 或 macOS 网络配置。
- 不读取 Clash Verge 配置文件、Secret 或私有 IPC。

## 统计口径

无法可靠识别出口类型的流量进入未知分类，不会根据节点名称或匹配规则进行猜测。界面将同时展示分类覆盖率，避免把不完整结果描述为计费级精确数据。

MVP-1 不保存今日或总累计，本机实时分类也不等同于机场计费流量。

## 测试数据

公开仓库中的响应样例必须经过脱敏，不得包含真实订阅、节点、域名、IP、进程路径或用户标识。
