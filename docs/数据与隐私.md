# 数据与隐私

## 原则

Mihomo Meter 采用本地优先、最小采集和明确口径原则。

## 计划保存的数据

- 分钟级 Proxy、DIRECT、REJECT 和未知流量汇总
- 本地统计记录点
- Mihomo 内核会话标识和版本
- 不含 Secret 的 Controller 设置

## 不保存的数据

- Controller Secret 明文
- 订阅地址和访问令牌
- 完整域名或目标 IP
- 进程完整路径
- 单连接长期明细
- 网络内容

Controller Secret 计划保存在 macOS Keychain，本地数据库只保存必要引用。

## 网络行为

- 默认只允许连接 `127.0.0.1` 或 `::1` 上的 Controller。
- 不向项目维护者或第三方上传流量统计。
- 不修改 Mihomo、Clash Verge Rev 或 macOS 网络配置。

## 统计口径

无法可靠识别出口类型的流量进入未知分类，不会根据节点名称或匹配规则进行猜测。界面将同时展示分类覆盖率，避免把不完整结果描述为计费级精确数据。

## 测试数据

公开仓库中的响应样例必须经过脱敏，不得包含真实订阅、节点、域名、IP、进程路径或用户标识。
