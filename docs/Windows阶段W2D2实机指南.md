# Windows 阶段 W2D-2 实机指南

## 1. 验收定位

本指南用于 Windows 10 22H2 x64 标准用户验证历史归因账本、榜单、覆盖率和趋势。执行前确认对应提交的“Windows 构建与测试”成功，再下载并解压名称以 `mihomo-meter-windows-w2d-x64-` 开头的 artifact。

不要上传 Controller Secret、订阅 URL、连接 ID、真实主机名、应用名称、进程路径、目标、数据库或本机路径。反馈可用虚构名称描述榜单和趋势。

## 2. 自动化与基础回归

1. 确认静态检查、Core 单元测试、App x64 Release 构建和非打包自包含发布全部成功。
2. 以标准用户启动，不以管理员身份运行 Meter 或 Mihomo 客户端。
3. 快速确认 W0-W2D-1 的通知区域、悬浮图标、实时分类、核心累计、统计任务、订阅配额、Proxy/DIRECT 实时连接和 Top 5 没有回归。
4. 应用标题应标识 Windows W2D-2，“Proxy 流量”顶部应包含“流量统计 / 实时连接 / 归因历史”三个稳定分段。

任一既有能力回归，应停止验收并反馈。

## 3. 默认关闭与启停边界

1. 首次打开“归因历史”，确认“记录日聚合”默认关闭；关闭状态下制造 Proxy 流量并等待超过 10 秒，刷新后榜单不得增加。
2. 开启开关，确认弹窗明确说明只记录本地日期、应用名称、完整主机名和上下行 Proxy 聚合，不包含连接明细、IP、端口或进程路径。
3. 开启后制造可识别应用和域名的 Proxy 上传/下载，等待约 10 秒并刷新；当天应用榜、域名榜和已记录字节应增加。
4. 制造 DIRECT 流量，确认历史归因不增加；无法识别的 Proxy 维度只能进入“未知应用”或“未知域名”。
5. 关闭开关前制造少量 Proxy 流量但不要等待 10 秒；关闭后立即刷新，确认关闭动作已强制写入这部分流量。继续制造流量后榜单不得再增加。

## 4. 日期、筛选与覆盖率

1. 日期下拉应固定覆盖包含今日的最近 30 个本地自然日；无数据日期显示空榜单而不是复用其他日期结果。
2. 分别选择应用和域名筛选，确认两个榜单使用精确交叉条件；切回“全部应用 / 全部域名”恢复完整当日排名。
3. 榜单按上下行总字节降序，行内同时显示下载、上传和合计；数据刷新时既有行不得整表闪烁或无故跳序。
4. “主机名流量覆盖”“应用流量覆盖”“完整流量归因”按字节变化；缺失维度会降低对应比例。
5. “归因记录覆盖”显示已归因字节、核心 Proxy 字节和比例。该值不代表开关开启时长，短时间内允许因 10 秒批处理出现差异。

## 5. 三十天趋势窗口

1. 点击应用榜行，确认打开独立应用趋势窗口；若当前选择了域名，窗口应显示继承的域名筛选。
2. 点击域名榜行，确认复用同一个窗口并切换目标；若当前选择了应用，窗口应显示继承的应用筛选。
3. 图表固定补齐 30 天，具有可读 X/Y 轴刻度、下载/上传堆叠柱和固定高度的日期明细区。悬停不同柱时明细变化，但页面布局不得跳动。
4. 核对 30 天合计、活跃日均、峰值日和有流量天数；峰值并列时应选择较新的日期，默认明细定位最近非零日。
5. 快速切换两个榜单目标，旧请求结果不得覆盖新目标；重复点击同一目标或点击“刷新”应重新查询。关闭窗口后再次打开，不得短暂显示上次目标。

## 6. 生命周期、清理与恢复

1. 开启记录并制造不足 10 秒的 Proxy 流量，随后停止监控或明确退出；重启后确认待写增量已强制保存。
2. 重启应用后开关状态和最近 30 天日聚合仍存在，但实时连接明细不得恢复。
3. 点击“清空归因历史”，确认只清空应用/域名日聚合，核心 Proxy 累计、统计任务、配额、Controller 配置和凭据保留。
4. 再次产生少量数据后，从“流量统计”执行“清空本地统计”，确认核心流量、统计任务和归因历史同时清空，配额与配置仍保留。
5. 观察开启记录后的空闲与持续传输体验；不要求提交精确 CPU、内存或数据库数值，但若出现持续卡顿、明显写盘尖峰或数据库异常增长，应判定失败。

不要为了测试故障隔离手工破坏 SQLite、删除 WAL/SHM 或修改 schema。

## 7. 通过标准与反馈

通过需要同时满足：CI 全绿；默认关闭；只记录可靠 Proxy；10 秒与四类强制刷新正确；30 天保留和筛选语义正确；四项覆盖率可解释；趋势窗口坐标、悬停、摘要和请求代际正常；两种清理边界正确；重启恢复日聚合但不恢复连接明细；归因异常不影响 W0-W2D-1。

反馈只需提供 Action run 链接、失败步骤、预期/实际、是否验证默认关闭/开关强制刷新/交叉筛选/趋势窗口/两种清理，以及是否观察到明显性能异常。不要附带真实榜单内容或数据库。
