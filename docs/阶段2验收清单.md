# 阶段 2 订阅余额人工验收清单

本清单用于完成自动化检查无法替代的 macOS 界面与真实环境验收。测试时不要在截图、日志或反馈中暴露订阅地址、Token、节点名称或完整 Profile 路径。

## 验收前准备

- [ ] 当前分支远端 CI 的格式、脚本、无签名构建和测试全部通过。
- [ ] 准备一个可由 Mihomo 暴露配额的当前订阅。
- [ ] 如需验证指定 Profile，再准备至少两个远程订阅 Profile，并确认其中一个是当前 Profile。
- [ ] 记录测试前是否已经授权 Profile 目录，便于核对清除行为。

## 轻量模式

- [ ] 未授权 Profile 目录时，状态栏快速菜单只在 Mihomo 暴露唯一有效配额候选后提供轻量追踪确认。
- [ ] 确认后显示剩余流量、已用、总量、更新时间、趋势和预计耗尽状态。
- [ ] 样本不足时显示明确原因，不显示伪造的预计天数。
- [ ] 候选变为零个、多个或来源变化时自动暂停，不继续猜测归属。

## 指定 Profile 模式

- [ ] 首次选择 Profile 目录只弹出一次系统授权；重新启动后可恢复授权，不重复弹窗。
- [ ] 当前 Profile 默认展开，非当前 Profile 收起并显示名称、剩余量、更新时间和查询状态。
- [ ] 快速菜单使用 AppKit 原生 `NSMenu` 外壳、扁平分区、留白和分隔线，不为 Profile 增加白底圆角卡片。
- [ ] 快速菜单默认展示最近 24 小时总消耗折线面积图，X/Y 轴保留紧凑刻度，首尾端点均有标记且不被裁剪；Y 轴按当前范围极值动态缩放，下载、上传增量用不同颜色堆叠，面积不得越出绘图区覆盖其他界面。
- [ ] 手动查询和全部查询必须经过当前 Mihomo；Mihomo 不可用时按钮禁用并保留最近历史。
- [ ] 完整统计窗口通过侧边栏进入“订阅余额”，同屏显示多个 Profile，不出现左侧 Profile 列表与右侧详情布局。
- [ ] 完整统计窗口统一切换 24 小时、7 天、30 天、12 月范围，主卡片按宽度自适应展示真实快照，空间不足时降为单列。
- [ ] 每张订阅卡片提供放大入口；大图显示同一累计趋势，不出现聚合粒度菜单或横向滚动。
- [ ] 快速菜单、完整窗口主卡片与放大图均支持悬停；快速菜单使用垂直指示线、选中点和图下固定明细，显示快照时间、累计下载、累计上传、总消耗、较前一展示点的三项增量和实际间隔。

## 趋势与变化事件

- [ ] 观察不足 6 小时、数据过期、近期无消耗、订阅到期或额度耗尽时显示对应原因。
- [ ] 用量下降后出现“待确认新周期”，确认前不输出耗尽预测。
- [ ] 点击“确认新周期”后警告消失，新周期积累足够样本后恢复预测。
- [ ] 总额度增加、总额度减少或到期时间变化后，在对应 Profile 中显示变化摘要。
- [ ] 剩余流量继续作为主数字、剩余比例进度和耗尽预测依据；图表上方显示本范围可比较区间的下载、上传与合计新增，默认图表直接展示真实快照累计值，不推测小时或每日用量。
- [ ] 24 小时、7 天、30 天、12 月范围只读取本地账本；切换不触发机场查询或重置下一次自动查询时间。
- [ ] 图表按宽度约每 40pt 一个点设置 2 至 30 个普通目标，每个套餐周期首尾强制点优先，中间按等分目标时间取最近快照。
- [ ] 多套餐周期互不连接，周期首点不计算跨周期增量；当前周期的日均消耗和预计耗尽结果保持原口径。
- [ ] 本范围新增分别汇总各套餐周期或异常回退断段内的可比较增量，不跨断点直接相减。
- [ ] 01:00 至后天 01:00 等长时间缺口保留直线，悬停显示真实起止时间和间隔，不把连线描述为匀速消耗。
- [ ] 同周期累计上传或下载异常回退时趋势断开，不把负增量修饰为零。
- [ ] 自然桶增量与旧柱图实现没有正式界面、设置、菜单、快捷入口或自动回退路径。

## 清除与隐私

- [ ] 完整订阅余额窗口的更多菜单提供“清空订阅余额数据”，系统确认对话框明确说明删除和保留范围。
- [ ] 确认清除后，轻量订阅、Profile 选择、趋势、变化事件和查询状态全部归零。
- [ ] 清除后 Controller 地址与 Secret 仍可使用，Profile 目录授权仍然有效，但 Profile 需要重新选择。
- [ ] Proxy 流量统计和秒表式任务不受订阅余额清除影响。
- [ ] 诊断日志不出现 Profile 名称、真实 UID、订阅地址、Token、UA 原文、完整响应头或正文。
