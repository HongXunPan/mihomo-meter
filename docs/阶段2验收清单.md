## 轻量模式

- [x] 未授权 Profile 目录时，状态栏快速菜单只在 Mihomo 暴露唯一有效配额候选后提供轻量追踪确认。
- [x] 确认后显示剩余流量、已用、总量、更新时间、趋势和预计耗尽状态。
- [x] 样本不足时显示明确原因，不显示伪造的预计天数。
- [x] 候选变为零个、多个或来源变化时自动暂停，不继续猜测归属。

## 指定 Profile 模式

- [x] 首次选择 Profile 目录只弹出一次系统授权；重新启动后可恢复授权，不重复弹窗。
- [ ] 快速菜单为每个 Profile 固定显示名称、当前标记、剩余量、总量和预计可用时长；较长时长按月、年自然展示，操作故障优先覆盖预测。整行进度轨道按剩余比例着色，子菜单往返后不变灰，不保留展开状态或大块空白。
- [x] 快速菜单使用 AppKit 原生 `NSMenu` 外壳、扁平分区、留白和分隔线，不为 Profile 增加白底圆角卡片。
- [x] 快速菜单首次展开不自动聚焦分类、路由、统计或订阅内联控件；自定义内容只使用鼠标，不纳入 `Tab` 焦点循环，底部标准菜单命令保留系统键盘导航与快捷键。
- [ ] 原生“查看订阅走势”子菜单固定尺寸，默认展示当前 Profile；多 Profile 使用左右按钮切换且保持菜单展开，精确 Profile 的立即查询遵守代理和冷却约束，轻量追踪不显示伪查询入口。
- [ ] 子菜单显示最近更新时间、精确 Profile 的下次查询或操作状态，轻量追踪显示无独立查询计划；额度区显示剩余量、精确比例、进度轨道、已用、总量和状态。
- [ ] 子菜单的 24 小时/7 天普通按钮与主界面分段控件视觉一致，但不使用 `Picker`；选择后菜单保持展开并立即显示新范围。趋势摘要、X/Y 轴、首尾端点、颜色和裁剪均正确；切换不触发查询，也不改变预测。
- [ ] 更新时间不足 60 秒显示“刚刚”，查询或重试即将到点显示“即将”，主菜单、趋势子菜单和完整统计窗口均不出现“0 秒后”。
- [x] 手动查询和全部查询必须经过当前 Mihomo；Mihomo 不可用时按钮禁用并保留最近历史。
- [x] 自动重试时间不阻止手动查询；网络型失败结束后可立即重试，其他查询的 60 秒手动冷却到期后按钮无需刷新页面即可自动启用。
- [x] 完整统计窗口通过侧边栏进入“订阅余额”，同屏显示多个 Profile，不出现左侧 Profile 列表与右侧详情布局。
- [x] 完整统计窗口统一切换 24 小时、7 天、30 天、12 月范围，主卡片按宽度自适应展示真实快照，空间不足时降为单列。
- [x] 每张订阅卡片提供放大入口；大图显示同一累计趋势，不出现聚合粒度菜单或横向滚动。
- [ ] 趋势子菜单允许 Profile、范围、立即查询和真实展示点悬停；悬停只替换固定明细与选中标记，离开恢复最新点，不显示浮层或改变尺寸。光标停留在图表时连续切换 Profile、24 小时/7 天或关闭重开菜单，旧事件不得覆盖当前点，也不得出现 `AttributeGraph cycle`；完整窗口主卡片与放大图继续显示同口径悬停明细。

## 趋势与变化事件

- [x] 观察不足 6 小时、数据过期、近期无消耗、订阅到期或额度耗尽时显示对应原因。
- [x] 用量下降后出现“待确认新周期”，确认前不输出耗尽预测。
- [x] 点击“确认新周期”后警告消失，新周期积累足够样本后恢复预测。
- [x] 总额度增加、总额度减少或到期时间变化后，在对应 Profile 中显示变化摘要。
- [x] 剩余流量继续作为主数字、剩余比例进度和耗尽预测依据；图表上方显示本范围可比较区间的下载、上传与合计新增，默认图表直接展示真实快照累计值，不推测小时或每日用量。
- [x] 24 小时、7 天、30 天、12 月范围只读取本地账本；切换不触发机场查询或重置下一次自动查询时间。
- [x] 图表按宽度约每 40pt 一个点设置 2 至 30 个普通目标，每个套餐周期首尾强制点优先，中间按等分目标时间取最近快照。
- [x] 多套餐周期互不连接，周期首点不计算跨周期增量；预计耗尽固定使用当前确认周期内最多近 7 天的有效快照，不随图表范围切换。
- [x] 本范围新增分别汇总各套餐周期或异常回退断段内的可比较增量，不跨断点直接相减。
- [x] 01:00 至后天 01:00 等长时间缺口保留直线，悬停显示真实起止时间和间隔，不把连线描述为匀速消耗。
- [x] 同周期累计上传或下载异常回退时趋势断开，不把负增量修饰为零。
- [x] 自然桶增量与旧柱图实现没有正式界面、设置、菜单、快捷入口或自动回退路径。
