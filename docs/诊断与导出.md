# 诊断与导出

## 本地诊断日志

Debug 与正式版本均在应用沙盒写入脱敏诊断日志：

```text
~/Library/Containers/com.HongXunPan.MihomoMeter/Data/Library/Logs/MihomoMeter/diagnostics.log
```

日志只记录应用启动与签名粗粒度状态、Keychain 操作阶段和数值状态码、连接取消与重连原因、共享核心路由状态，以及 Profile 配额查询的本地标识、短指纹和类型化结果。它不记录 Controller Secret、地址及长度、Profile 名称或真实 UID、订阅地址、Token、节点、UA 原文、请求或响应、错误原文、完整路径或连接目标，也不上传。

单文件上限 512 KiB，只保留当前与一份轮换日志；超过 7 天未更新会在下次写入前删除。帮助菜单可打开诊断目录；应用停止后可删除日志，后续会按需重建。

## 用户诊断导出

macOS 与 Windows 均在设置页提供“导出诊断信息”。应用先展示包含与排除范围，用户确认后再由系统保存面板选择位置；取消选择不会生成文件，文件也不会自动上传。

导出文件是 UTF-8 JSON v1，只包含：

- 应用版本与构建号；
- 系统版本与架构；
- 固定连接状态；
- 当前会话最多 200 条脱敏事件。

事件来自独立的内存白名单快照，不读取原始日志；固定类别之外只允许固定状态、数值错误码、耗时、超时和退避。Windows 当前会话与 macOS 对齐覆盖凭据读取/保存/删除、连接尝试/建立/stale/取消/重连/停止，以及 Profile 配额查询开始与结束；平台名称可以不同，但事件语义和排除范围一致。

## 排除范围

导出文件不包含：

- Controller 地址或 Secret、Keychain/Credential 内容；
- `traffic.sqlite3`、`quota.sqlite3`、`connection-analytics.sqlite3`；
- 请求标识、订阅 UUID、Profile UID、地址指纹或业务名称；
- 文件路径、主机名、应用名、连接目标、节点或规则；
- 原始错误文本、日志原文、请求或响应内容。

Windows 对自由文本事件字段还执行固定字符集和长度校验，不满足白名单时写入 `unknown`，不会原样进入文件。

## 验收边界

自动测试覆盖 JSON v1、200 条上限、标识符剔除和非法自由文本降级。macOS 的完整构建由 CI 门禁执行，Windows 的完整构建由 Windows CI 执行；两端仍需实机确认范围提示、取消不写文件、覆盖保存、权限拒绝和文件内容。
