# 跨平台共享核心 P2-5 运行态验收指南

## 1. 文档定位

- 状态：待双端实机验收
- 适用范围：P2-4 代理类型受保护主路径
- 目标：确认共享分类只在与原生分类精确一致时进入生产结果，异常仍安全回退

本指南只验证 P2-5 运行态门禁，不替代发布或完整功能回归。确定性测试继续覆盖 14 种现行代理协议、DIRECT、REJECT、未知、错误与输入边界；实机必须覆盖明确 Proxy、DIRECT 与空闲切换。

## 2. 前置条件与证据边界

1. 使用 P2-4 合并后的同一 `main` commit，通用 CI 与 Windows CI 均须通过。
2. macOS 和 Windows 各执行至少两次独立启动，其中一次完全退出后的冷启动；每个平台至少连续连接 30 分钟。
3. Windows 使用 Windows 10 22H2 x64 标准用户和对应 CI 产物；macOS 使用源码仓 `scripts/build-debug.sh` 前台启动。
4. 只记录平台、系统版本、构建 commit、起止时间、启动次数、场景结论以及粗粒度 `source + status`；不得复制完整日志或记录原始代理类型、节点、链路、地址、Secret、订阅及连接目标。

## 3. 场景与界面核对

每个平台依次执行“连接空闲 → 明确 Proxy 流量 → 明确 DIRECT 流量 → 再次空闲”，并核对：

- Proxy、DIRECT、REJECT 和未知继续分开，速率、累计流量及连接分析方向合理；
- 目录刷新、断开重连、账本累计和空闲恢复保持原行为；
- 无启动、连接、界面响应或明显 CPU、内存、唤醒退化。

去重后的单条成功日志只证明受保护路径至少执行一次，不能代替 Proxy 与 DIRECT 的可控场景和界面核对。

## 4. macOS 验收

```bash
sh scripts/build-debug.sh
```

只筛选受保护路由事件：

```bash
grep 'event=shared_core.proxy_type_route' \
  "$HOME/Library/Containers/com.HongXunPan.MihomoMeter/Data/Library/Logs/MihomoMeter/diagnostics.log"
```

每个进程至少出现一次：

```text
event=shared_core.proxy_type_route source=shared_primary status=matched
```

同一进程每个 `source + status` 组合最多一次。若自然出现共享未识别，允许一次 `source=native_fallback status=unrecognized`，但未知口径必须不变。不得出现旧生产 `shared_core.proxy_type_shadow` 事件或其他回退状态。

## 5. Windows 验收

从同一 commit 的 Windows CI 下载预览产物，以标准用户在 PowerShell 中启动：

```powershell
$env:MIHOMO_METER_STARTUP_CONSOLE = "1"
.\MihomoMeter.Windows.App.exe
```

每个进程至少出现：

```text
WINDOWS_STAGE stage=shared_core_runtime_ready
WINDOWS_DIAGNOSTIC event=shared_core.proxy_type_route source=shared_primary status=matched
```

去重和允许的 `native_fallback + unrecognized` 规则与 macOS 相同。不得出现旧生产影子事件、其他回退状态、`WINDOWS_FAILURE`、标准用户启动异常或 DLL 加载失败。

## 6. 放行与停止条件

双端均满足“两次启动 + 一次连续 30 分钟 + Proxy/DIRECT/空闲切换 + `shared_primary + matched` + 无禁止状态 + 分类和账本不变”，P2-5 才能通过。缺少成功事件不能按“未发现异常”放行。

出现 `abi_mismatch`、`native_call_failed`、`unsupported_input`、`input_too_long`、`unexpected_result`、`mismatch`、`unknown_failure`、重复诊断、敏感内容、流量混类、账本异常、连接异常或明显资源退化时立即停止；不得进入 P2-6。
