# MVP-2 秒表式流量统计

## 能力范围

MVP-2 在 MVP-1 实时分类的基础上增加本机累计和秒表式统计任务：

- 展示今日与本机总累计；
- 保存 Proxy、DIRECT、REJECT 和未知分类字节数；
- 允许同时开始多个统计任务；
- 每个任务只展示 Proxy 上传、下载和合计；
- 支持重命名、停止和删除任务。

统计任务不是独立采集器。所有任务共享同一份底层流量账本，只保存各自开始和结束时的 Proxy 累计基线，因此并行任务不会复制分钟桶。

## 使用方式

1. 打开状态栏快速菜单，进入紧随 Proxy 摘要的原生“统计任务”子菜单并选择“开始新统计”。
2. 应用按现有任务数量自动生成“统计任务 N”并立即开始，不激活应用或前置完整统计窗口。
3. 任务进行中会按照当前 Proxy 本机累计与开始基线的差值更新。
4. “统计任务”父项以纯计数 Badge 展示全部进行中数量，完整状态保留在无障碍描述和子菜单页头；子菜单固定五个槽位，进行中任务优先，剩余位置由本地今日已完成或已中断任务补足。每个槽位展示 Proxy 下载、上传、合计和时间信息；开始和停止只替换槽位内容且保持菜单展开，点击任务主体会关闭菜单并进入“Proxy 流量 / 流量统计”，超过五条时进入完整统计窗口。
5. 独立统计窗口可按“进行中、历史记录、全部”筛选，并支持使用自定义名称新建、重命名、停止或删除任务。

删除任务只删除该区间，不会修改底层累计或其他任务。当前版本不提供暂停、恢复、导出或手工修改基线。

状态栏快速菜单的自定义内容只承担鼠标快速查看和原地操作，不纳入 `Tab` 焦点循环，点击外部会自动收起；“统计任务”使用标准父菜单项和固定尺寸真实子菜单，长期持有的 SwiftUI 根视图以五个稳定索引槽位承载快捷开始、任务摘要和停止按钮，操作时不关闭菜单、不重建根视图或增删槽位。“查看 Proxy 流量统计”和“查看订阅余额统计”使用标准菜单项并分别紧跟对应摘要，连同底部命令保留系统键盘导航与快捷键。完整统计窗口不会因点击窗口外部而关闭，
用于承载持续增长的历史任务；清空全部统计仍要求用户在系统确认框中明确选择。

## 状态与中断

- **进行中**：统计链路可用，持续计算 Proxy 基线差值。
- **已完成**：用户正常停止，结果固定保存。
- **已中断**：应用退出、用户主动断开、鉴权或兼容性终止、崩溃恢复，或统计链路无法继续；结果只包含最后一次成功观测之前的流量。

WebSocket 重连和睡眠恢复本身不会中断任务。若内核累计仍可单调衔接，无法分类的间隔进入未知，不会计入任务的 Proxy 总额；若内核累计回退，则建立新的本地内核会话，任务继续使用本机 Proxy 总累计，不会重复归零。

应用未运行期间不补算流量。崩溃或强制终止后，下次启动会把遗留的进行中任务收口为“已中断”，结束时间取最后一次成功持久化的观测时间。

## 数据保留

- 分钟级分类桶保留 365 天；
- 每日分类汇总和统计任务不随分钟桶清理；
- 每份增量按观测时的系统时区归入本地日期；
- 之后修改系统时区不会重写历史日期。

第一份连接快照只建立基线。累计直接消费原始分类增量，不会从两秒平滑速率反推。

## 清空与隐私

“清空本地统计”会删除账本和全部统计任务，并重新建立空数据库。清空后的下一份观测只建立新基线，避免把清空前后的采样窗口重新写入。

清空不会删除：

- 服务地址；
- macOS 登录钥匙串中的访问密钥（Secret）。

SQLite 数据库只保存分类字节数、时间、本地 UUID 和用户填写的任务名称或备注，不保存连接目标、节点、进程、原始响应或 Secret。更完整的边界见[数据与隐私](数据与隐私.md)。
