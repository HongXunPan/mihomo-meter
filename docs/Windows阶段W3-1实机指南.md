# Windows 阶段 W3-1 实机指南

## 1. 用途与边界

本文用于 Windows 10 22H2 x64 标准用户验证 unsigned NSIS 当前用户安装、运行中阻断、覆盖升级、卸载、重装、便携版共存和用户数据保留。W3-1 仍只生成 GitHub Actions 预览 artifact，不创建 Tag、GitHub Release 或应用内更新入口。

测试期间不要上传 Controller Secret、订阅 URL、真实主机名、应用名称、进程路径、数据库、设置文件或本机路径。反馈只需提供提交 SHA、Action run 链接、测试版本和失败步骤。

## 2. 版本、下载与校验

1. PR 和 `main` push 默认生成 `0.0.0` 预览；覆盖升级需要再手动运行“Windows 构建与测试”，输入另一个无前导零的版本，例如 `0.0.1`。
2. 每个 artifact 应且只应包含：

```text
Mihomo-Meter-X.Y.Z-windows-x64-portable.zip
Mihomo-Meter-X.Y.Z-windows-x64-setup.exe
SHA256SUMS
```

3. 在 **PowerShell** 中进入 artifact 目录后执行；不要在 `cmd.exe` 中逐行输入：

```powershell
Get-Content .\SHA256SUMS | ForEach-Object {
    $Expected, $Name = $_ -split '  ', 2
    $Actual = (Get-FileHash -LiteralPath $Name -Algorithm SHA256).Hash.ToLowerInvariant()
    if ($Expected -ne $Actual) { throw "SHA-256 不一致：$Name" }
    Write-Host "SHA-256 通过：$Name" -ForegroundColor Green
}
```

4. 确认安装器和应用文件版本均与资产名中的 `X.Y.Z` 一致；安装器未签名属于当前已知边界。

## 3. 首次安装与启动

1. 使用标准用户双击 `setup.exe`，不要选择“以管理员身份运行”；首次下载可能出现 SmartScreen，确认来源后继续。
2. 安装全程不得出现 UAC。首次安装应显示目录选择页，默认值为 `%LOCALAPPDATA%\Programs\Mihomo Meter`；改选其他磁盘上的空专用目录，例如 `D:\Apps\Mihomo Meter`，确认可以继续。
3. 分别尝试磁盘根目录、`%LOCALAPPDATA%\HongXunPan\MihomoMeter`、无写权限目录和已有文件的非空目录，确认安装器拒绝继续且不会删除其中内容。
4. 确认欢迎页、目录页、安装/升级/卸载阻断提示、危险目录提示、完成页标题/正文/按钮和“运行 Mihomo Meter”等全部文字均清晰显示，不再出现缺字、乱码或英文字母笔画残缺。
5. 确认开始菜单出现 “Mihomo Meter”，桌面没有自动创建快捷方式，“已安装的应用”中存在当前版本和卸载入口，`InstallLocation` 与所选目录一致。
6. 完成页保持“运行 Mihomo Meter”后结束安装，确认标题显示“Windows W3-1”，且只有一个进程和通知区域图标。
7. 快速确认 Controller 配置、Credential Manager、Proxy/DIRECT 实时速度、核心累计、统计任务、订阅配额、实时连接与历史归因可以正常进入。

## 4. 运行中处理与覆盖升级

1. 先安装较低版本并启动应用，再运行较高版本安装器。
2. 安装器必须提示应用仍在运行，并只提供“重试 / 取消”；不得强制结束进程、静默覆盖或触发 UAC。
3. 选择取消后，旧版本应继续运行，程序文件、开始菜单、配置、凭据和业务数据不变。
4. 再次运行较高版本安装器，从通知区域明确退出旧版本后选择重试；升级必须跳过目录选择并继续使用较低版本的已登记目录，确认完成后没有第二个程序目录、残留旧版本文件或重复快捷方式。
5. 启动新版本，确认“已安装的应用”、安装器、应用文件版本一致；原 Controller 地址、凭据、核心累计、配额和归因数据继续可用。
6. 再次运行同版本安装器，确认可完成原位重装且不会创建第二个安装目录或卸载入口。

## 5. 卸载、重装与便携版共存

1. 应用运行时从“已安装的应用”发起卸载，确认卸载器要求从通知区域明确退出，并且不会强制结束应用。
2. 退出后完成卸载，确认已选择的程序目录、开始菜单和卸载入口消失，且没有残留进程或通知区域图标。
3. 确认 `%LOCALAPPDATA%\HongXunPan\MihomoMeter` 仍保留，Windows Credential Manager 中以 `com.HongXunPan.MihomoMeter` 开头的既有凭据未被删除。
4. 重新安装时选择另一个空目录，确认这才会完成程序目录迁移；启动后原配置、凭据和业务数据恢复可用。
5. 解压同版本便携 ZIP，确认安装目录与便携目录可以同时保留；先启动安装版再启动便携版、先启动便携版再启动安装版，后启动进程都必须退出并恢复既有窗口。
6. 每次从通知区域明确退出主实例后等待 5 秒，确认任务管理器“进程”和“用户”下都不再存在 `MihomoMeter.Windows.App`；只有窗口与通知区域图标消失、进程仍残留也必须判定失败。
7. 再复制到两个不同便携目录并双向启动，确认始终只有一个进程和一个通知区域图标；既有实例完整退出后，任一目录都能成为新的主实例。两种分发形态仍共享当前用户数据和单实例身份，不能作为两套独立应用同时运行。
8. 只有用户明确决定清空数据时，才在应用完全退出后手动删除 `%LOCALAPPDATA%\HongXunPan\MihomoMeter`，并通过 Windows“凭据管理器”删除对应 Mihomo Meter 凭据；卸载器不得代替用户执行该操作。

## 6. 通过标准与停止条件

通过需要同时满足：CI 全绿；三个资产结构和两项 SHA-256 正确；中文与英文文字显示正常；首次安装可选择其他磁盘且拒绝危险目录；安装、升级、卸载不触发 UAC；运行中操作不会强制结束或覆盖；升级锁定既有目录；开始菜单和卸载入口正确；卸载保留用户数据与凭据；重装迁移与恢复成功；便携版共存边界明确；W0-W2D 业务与通知区域右键没有回归。
