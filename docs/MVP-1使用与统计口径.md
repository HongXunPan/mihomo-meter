# MVP-1 使用与统计口径

## 使用前提

Mihomo Meter 依赖 Mihomo 的公开 External Controller API。使用前需在用户自己的 Mihomo 或 Clash Verge 设置中启用 Controller，并由用户手动取得地址和 Secret。

MVP-1 只接受以下回环地址：

- `127.0.0.1:端口`
- `http://127.0.0.1:端口`
- `http://[::1]:端口`

应用不会读取 Clash Verge 配置文件，也不会通过私有 IPC 获取 Secret。

## 首次连接

1. 点击 macOS 状态栏中的 Mihomo Meter。
2. 展开“Mihomo 连接”，填写服务地址。
3. 填写访问密钥；Mihomo 未启用鉴权时可以留空。
4. 点击“连接”。

应用先调用 `/version` 验证连接和鉴权，再读取 `/proxies`。用户手动提交的配置验证成功后，地址写入应用设置，Secret 写入本应用的 macOS Data Protection Keychain，随后建立 `/connections?interval=500` WebSocket。应用启动和自动重连会复用已加载的 Secret，不重复写入 Keychain。

### 凭据存储与开发签名

Data Protection Keychain 使用应用签名中的 App ID 隔离凭据。正式发布版本保持固定 Bundle ID 和开发团队后，正常启动不会要求用户为 Controller Secret 选择“允许”或“始终允许”。

应用不读取或自动迁移开发阶段遗留的传统文件型 Keychain 条目；切换到 Data Protection Keychain 后需要重新填写一次 Secret。本地开发应通过被 Git 忽略的 `Config.local.xcconfig` 提供自己的 `DEVELOPMENT_TEAM`，不要把个人 Team ID 写入 Xcode 工程文件；切换开发团队或签名身份会进入新的访问组，同样需要重新填写。

Debug 构建会生成不含 Secret 的本地诊断日志，具体位置、字段和清理方式见[数据与隐私](数据与隐私.md#debug-诊断日志)。

## 实时统计口径

### 分类

每个活动连接使用 `chains.first` 作为已验证的叶子出口候选，再通过 `/proxies.type` 分类：

- 具体代理协议：Proxy
- `Direct`：DIRECT
- `Reject` 或 `RejectDrop`：REJECT
- 链为空、目录缺失、策略组或类型不明确：未知

应用不会根据节点名称、匹配规则或外层策略组猜测分类。链式代理的业务字节只累计一次。

### 增量

首份连接快照只建立基线。后续按连接 ID 计算上传和下载计数的非负增量；首次出现的新连接从零计算，计数回退时重新建立该连接基线。

活动连接可能在两个快照之间创建并结束。此类无法取得连接链的流量通过内核总增量残差进入未知：

```text
已分类 = Proxy + DIRECT + REJECT
未知 = max(内核总增量 - 已分类, 0)
分类可信度 = 已分类 / 内核总增量
```

### 速率

- WebSocket 请求间隔：500 毫秒
- 原始窗口：按单调时钟聚合的完整 1 秒窗口
- 默认展示：最近两个完整 1 秒窗口的简单平均
- 诊断区：当前原始 1 秒 Proxy 速度

连接正常时，状态栏展示 Proxy 下载和上传速度；未连接、连接中、重连、数据超时、鉴权失败或响应不兼容时，改为展示明确状态，不以 `0 B/s` 代替异常。弹层同时展示 DIRECT、REJECT、未知、分类可信度和当前可确认的 Proxy 叶子。

分类可信度低于 95% 时，百分比和警告图标会显示为橙色；鼠标停留在该区域可查看“当前结果不适合用于精确判断”的完整说明。提示不占用额外布局空间，也不修改 Proxy、DIRECT、REJECT 或未知的原始统计值。

## 断线和异常

- 超过 2 秒没有新快照：实时速度归零并标记数据超时，但暂不取消 WebSocket；若 5 秒内恢复，继续复用原连接。
- 持续 5 秒没有新快照：使旧流失效并取消 WebSocket，旧流之后到达的迟到快照会被忽略。
- WebSocket 中断：按 `1、2、4、8、16、30` 秒上限退避重连；连接连续稳定 30 秒后，下一次中断从 1 秒重新开始。等待期间可以点击固定顶部区域中的“立即重连”取消当前退避。
- 鉴权失败：停止自动重试，等待用户修正 Secret。
- 响应结构不兼容：停止自动重试并显示错误。
- Controller 或连接计数回退：丢弃旧运行基线，避免负增量。
- 出现代理目录中不存在的新叶子：后台定向刷新一次 `/proxies`，不阻塞 WebSocket。

Debug 日志会使用固定枚举记录连接尝试来源、取消来源、最近快照间隔、自动重连原因、错误代码、等待秒数和结果，不写入服务地址、访问密钥、节点或原始错误文本。看门狗主动取消不会再记成外部网络断开。

## MVP-1 边界

MVP-1 只提供当前实时速度，不提供：

- 今日或总累计
- 手动统计记录点
- 应用重启后的恢复
- 机场订阅余额走势
- 本机统计与机场计费的强一致对账

这些能力分别属于后续 MVP-2 和订阅余额阶段。
