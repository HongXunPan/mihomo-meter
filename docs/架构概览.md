# 架构概览

## 目标

Mihomo Meter 采用原生 macOS 技术栈，在状态栏展示经过 Mihomo Proxy 出口的实时网速和累计流量。

## 技术栈

- Swift 6
- AppKit `NSStatusItem`
- SwiftUI
- `URLSession`
- `URLSessionWebSocketTask`
- SQLite
- macOS Keychain

## 分层

```text
状态栏与详情界面
        ↓
流量应用服务
        ↓
Mihomo Controller 集成
        ↓
本地流量账本与 Keychain
```

### Application

负责应用生命周期和模块装配，不承载连接分类或累计算法。

### Domain

保存与界面和网络实现无关的流量模型、分类规则和统计口径。

### Presentation

负责状态栏、弹层和用户可见状态，不直接解析 Mihomo 响应。

### 后续模块

Controller 接入阶段将按职责引入：

- `MihomoControllerClient`
- `ConnectionStreamCollector`
- `ProxyCatalog`
- `ConnectionDeltaTracker`
- `ProxyClassifier`
- `TrafficAggregator`
- `TrafficLedger`

模块只在进入对应实现阶段时创建，避免预先生成空接口和无行为文件。

## 稳定边界

1. Mihomo 集成只使用公开 Controller API。
2. Proxy、DIRECT、REJECT 和未知流量独立建模。
3. 连接级数据只用于内存计算，默认不持久化目标明细。
4. 断线时实时速率必须归零，不沿用旧值。
5. 本机累计不等同于机场计费流量。
